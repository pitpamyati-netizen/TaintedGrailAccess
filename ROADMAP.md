Для каждого игрового этапа отдельно фиксируются версия сборки и проверка NVDA.

## M3. Законченный карточный бой

- [x] Разделы статуса, руки, врагов, прислужников, ресурсов и конца хода.
- [x] Просмотр и tooltip карты не активируют её; актуальная стоимость/сторона.
- [x] Оригинальные handlers розыгрыша, targeting/cancel, quickcast settings.
- [x] Выбор N карт с явным счётчиком/подтверждением/допустимой отменой.
- [ ] Ultimate, все разновидности классовых механик и преобразование карт.
  Для девяти классов подключены текущая способность, классовая колода,
  показанные эффекты/уровни прислужников и стороны карт. В 0.3.4 дополнены
  пороги, отметки колоды и описания. Все разновидности ещё не проверены в игре;
  границы — [m3-class-coverage.md](docs/research/m3-class-coverage.md).
- [x] Видимые намерения, динамические эффекты, смена цели и исчезновение карты.
- [x] Событийная речь, краткий/полный журнал, победа/поражение/награда.

Gate: несколько разных боёв без мыши, включая многошаговые карты и смерть цели.
0.3.4: Graph 94, Runtime 84, Windows 18 утверждений, Python 21, ошибок 0;
сборка с игровыми DLL и точные привязки девяти классов проверены. Установлена
с проверенной резервной копией. Новые пути не приняты в игре/NVDA; окно
сохранения карты пока не появилось пользователю, продолжение не подтверждено.
Gate M3 открыт; все отметки реализации выше не означают полного завершения.
Историческая 0.3.2: исходники, переносимые проверки и сборка с игровыми DLL готовы;
пометки выше обозначают реализацию, а не игровую приёмку. Gate M3 остаётся
открытым: первый бой пользователь прошёл с NVDA на исходной 0.3.0.
Сводки и фокус руки 0.3.1 подтверждены пользователем. В установленной
0.3.2 исправлено мгновенное закрытие меню при удержании Escape. Пользователь
с NVDA подтвердил открытие, удержание, чтение пунктов стрелками, отдельное
закрытие и повторное открытие меню. Приняты отмена выбора цели при удержании
Escape без меню, возврат в руку и последующий Enter → выбор цели → Enter.
Несколько разных боёв и отмена поиска при удержании ещё требуют проверки.
В 0.3.3 исправлены названия значков ресурсов после боя; пользователь с NVDA
подтвердил их чтение и получение доступной награды через «Продолжить» за егеря.
Все варианты наград и поражение отдельно ещё не приняты. Однократный розыгрыш
при удержании Enter на цели подтверждён в 0.3.3. Также приняты удержание
при Alt+Tab и возврате без повтора и следующее нажатие после отпускания.
Пользователю пока доступен только Егерь; остальные классовые механики
остаются без приёмки до обычной разблокировки в прохождении.
В исходном EndTurn найден подозрительный
путь сохранения карты, пока без живого воспроизведения. Результаты и сценарий —
[M3_VERIFICATION.md](docs/M3_VERIFICATION.md).

- [x] Сканер видимых/раскрытых объектов без утечек скрытой информации.

Gate: игрок сам обнаруживает и выбирает достижимое событие, подходит и выходит.
0.4.2: исходники, переносимые проверки, сборка с игровыми DLL и обратимая
установка готовы. Graph 94, Runtime 94, Windows 18 утверждений, Python 21;
ошибок 0. Точные привязки и прямой опрос VHeroKeys проверены по метаданным.
Живая проверка 0.4.0 выявила запрет движения по предварительному пути.
В 0.4.1 этот запрет убран: решение принимает исходный обработчик игры.
Журнал 0.4.1 подтвердил подходы/диалоги/возвраты, пользователь сообщил о
пропущенных именах и непостоянном взаимодействии. В 0.4.2 исправлены подписи,
блокировка от обычной подсказки и объяснение недоступного места.
Повторное чтение/взаимодействие с NVDA ещё не принято; gate M4 открыт.
Отметки выше относятся к реализации, а не к подтверждённому прохождению.
Сценарий и ограничения — [M4_VERIFICATION.md](docs/M4_VERIFICATION.md).
