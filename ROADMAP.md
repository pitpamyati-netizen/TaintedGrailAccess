# Дорожная карта

`[x]` означает выполненную работу в архиве. Это не отметка проверки в игре.
Для каждого игрового этапа отдельно фиксируются версия сборки и проверка NVDA.

## M0. Независимый фундамент

- [x] Оригинал пользовательского Graph A11y дополнения.
- [x] Чистое BCL-ядро, builder, восстановление идентичности и announcer.
- [x] Навигатор, Live-watch, type-ahead, стеки экранов и модель ownership.
- [x] Изолированные поведенческие тесты и сценарии регрессий.
- [x] Windows speech bridge и diagnostic-only BepInEx 5 host.
- [x] Read-only inventory установки с проверкой PE/CLI и SHA-256.
- [x] Инструкции, coverage, источники и правила работы Codex.
- [x] Полезные дополнения Accessibility Mod Template: проверка меню, локализация,
  диагностика, журнал игровых привязок, работа с GitHub и подготовка выпуска.
  Состав переноса и исключения — в docs/research/template-import.md.
- [x] Проверить SDK-сборку диагностического host с файлами пользователя.
- [x] Подтвердить загрузку host и реальный вывод NVDA на этой сборке.
  GOG 1.61, Unity 2020.3.23f1, BepInEx 5.4.23.5, Windows x64;
  пользователь подтвердил стартовую речь 12 октября 2026.

## M1. Привязки и владение вводом

- [x] Установить точные Unity/runtime/game/loader versions и заполнить профиль.
  Локальный профиль GOG 1.61 содержит SHA-256/MVID; разрешения игровых действий
  и владения вводом остаются false.
- [x] Найти модели, правила видимости, идентичность и original UI handlers
  стартового меню, согласия, настроек и подтверждения в локальном коде.
  Действия ещё не подключены и не проверены в игре; подробности —
  docs/research/title-input-bindings.md. Типы элементов настроек исследуются по мере подключения.
- [x] Обработка снимков удерживаемых клавиш, отпускания, повторов и возврата окна;
  11 переносимых тестов. Ограниченное read-only наблюдение ввода 0.1.2 собрано,
  но ещё не запущено в игре. Это не завершает владение физическим вводом.
- [ ] Подтвердить input poll до обработки игры; Rewired/global keymap.
- [ ] Исключить двойной Submit через EventSystem/ownership handler guard.
- [ ] Эксклюзивная модальность, raw capture, реальные поля ввода, потеря окна.
- [ ] Пропуск неизвестных сочетаний и чистый возврат обычного управления.

Gate: каждое нажатие имеет ровно одно действие, обычные клавиши игры работают.
