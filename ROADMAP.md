# Дорожная карта

`[x]` означает выполненную работу в архиве. Это не отметка проверки в игре.
Для каждого игрового этапа отдельно фиксируются версия сборки и проверка NVDA.

- [x] Оригинал пользовательского Graph A11y дополнения.
- [x] Чистое BCL-ядро, builder, восстановление идентичности и announcer.
- [x] Навигатор, Live-watch, type-ahead, стеки экранов и модель ownership.
- [x] Изолированные поведенческие тесты и сценарии регрессий.
- [x] Windows speech bridge и diagnostic-only BepInEx 5 host.
- [x] Read-only inventory установки с проверкой PE/CLI и SHA-256.
- [x] Инструкции, coverage, источники и правила работы Codex.
- [x] Полезные дополнения Accessibility Mod Template: проверка меню, локализация,
  диагностика, журнал игровых привязок, работа с GitHub и подготовка выпуска.
  Состав переноса и исключения — в docs/research/template-import.md.
- [x] Проверить SDK-сборку диагностического host с файлами пользователя.
- [x] Подтвердить загрузку host и реальный вывод NVDA на этой сборке.
  GOG 1.61, Unity 2020.3.23f1, BepInEx 5.4.23.5, Windows x64;
  пользователь подтвердил стартовую речь 12 октября 2026.

## M1. Привязки и владение вводом

- [x] Точные Unity/runtime/game/loader versions и SHA-256/MVID GOG 1.61.
  Неподключённый пример профиля не получает разрешений; активный host допускает
  только исследованные отпечатки TG.Main, Rewired, Unity UI и TMP.
- [x] Модели, живая видимость, идентичность и оригинальные обработчики меню,
  согласия, настроек и подтверждения. Подключён ограниченный стартовый путь
  для проверки ввода; все типы настроек и весь путь обучения относятся к M2.
- [x] Снимки клавиш, отпускание, повтор навигации, одно действие при удержании
  Enter, потеря/возврат окна. 11 тестов tracker и 8 дополнительных регрессий.
- [x] Ранний опрос перед GameUI и EventSystem; подавление Rewired по живым
  картам и действительным физическим источникам текущего действия.
- [x] Защита от двойного Submit в Focus, ARButton, Button/Toggle и EventSystem;
  собственный вызов исходного обработчика проходит через область владения.
- [x] Собственная модальная справка Ctrl+F1, raw capture назначения клавиши,
  настоящий текстовый редактор, Alt+Tab и ожидание отпускания после возврата.
- [x] Неприсвоенные сочетания остаются игре; выключение флага и уничтожение
  стартовой сцены освобождают управление. KeyUp очищает штатный словарь игры.

Gate: одно нажатие — одно действие; обычные клавиши игры работают.
Проверка 13 октября 2026: сборка 0.1.3, GOG 1.61, NVDA. Пользователь подтвердил
меню, удержание/повтор, Alt+Tab, справку, отмену назначения и возврат из popup.
Передача текста штатному редактору, набор/удаление и Escape проверены;
озвучивание букв остаётся M2. Сценарий — docs/M1_VERIFICATION.md.
Доказательства и границы: docs/GAME_API.md и docs/TEST_RESULTS.md.

## M2. Первый доступный игровой путь

- [x] Пассивно читать живую стартовую подсказку Press Any Button.
  В 0.1.1 проверены игровой запуск и слышимость NVDA. В 0.1.3 также подключён
  ограниченный путь меню/настроек для проверки M1.
- [x] Press Any Button, главное меню, настройки, Continue/New Game/Back.
- [x] Ползунки, переключатели, списки, вкладки и диалоги подтверждения.
- [x] Речевой просмотр и редактирование настоящих текстовых полей.
- [x] Доступные текст/озвучивание TOS и решение пользователя.
  Видимый текст, ссылки и исходные accept/cancel подключены; повторная живая
  проверка условий на уже согласившемся профиле не выполнялась.
- [x] Сохранение фокуса при модальности, смене разрешения и rebind.
  Состояние хранится по модели/ключу, а view находится заново; возврат из popup
  и rebind принят с NVDA. Смена разрешения отдельно в игре не проверялась.
- [x] Новое обучение, выбор класса/сложности и вход в первый бой.
  Обучение ограничивает классы и запрещает изменение сложности по правилам игры.

Gate: слепой тестировщик проходит весь путь самостоятельно.
13 октября 2026, 0.2.0, GOG 1.61, NVDA: пользователь самостоятельно создал героя,
подтвердил загрузку, прошёл начальные диалоги, выбрал доступный класс и дошёл
до сообщения о первом бое. Основной путь M2 принят; это не приёмка карточного
боя, других режимов и каждого варианта настроек. Подробности —
[M2_VERIFICATION.md](docs/M2_VERIFICATION.md).

## M3. Законченный карточный бой

- [x] Разделы статуса, руки, врагов, прислужников, ресурсов и конца хода.
- [x] Просмотр и tooltip карты не активируют её; актуальная стоимость/сторона.
- [x] Оригинальные handlers розыгрыша, targeting/cancel, quickcast settings.
- [x] Выбор N карт с явным счётчиком/подтверждением/допустимой отменой.
- [ ] Ultimate, все разновидности классовых механик и преобразование карт.
  Общий handler, классовая колода, показанные эффекты/уровни прислужников
  и просмотр сторон подключены; все разновидности ещё не проверены в игре.
- [x] Видимые намерения, динамические эффекты, смена цели и исчезновение карты.
- [x] Событийная речь, краткий/полный журнал, победа/поражение/награда.

Gate: несколько разных боёв без мыши, включая многошаговые карты и смерть цели.
0.3.0: исходники, переносимые проверки и сборка с игровыми DLL готовы;
пометки выше обозначают реализацию, а не игровую приёмку. Gate M3 остаётся
открытым: нужны реальные бои с NVDA. В исходном EndTurn найден подозрительный
путь сохранения карты, пока без живого воспроизведения. Результаты и сценарий —
[M3_VERIFICATION.md](docs/M3_VERIFICATION.md).

## M4. Исследование и перемещение

- [ ] Сканер видимых/раскрытых объектов без утечек скрытой информации.

- [ ] Проверка используемого игрой pathfinder: A* или иной controller по фактам.
