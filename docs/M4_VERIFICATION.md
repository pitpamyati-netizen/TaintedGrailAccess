# Проверка M4, версия 0.4.0

13 октября 2026, Conquest GOG 1.61, Unity 2020.3.23f1, Mono x64,
BepInEx 5.4.23.5. Точные привязки и отпечатки —
[exploration-bindings.md](research/exploration-bindings.md).

## Реализованный путь

После боя/диалога появляется экран исследования без захвата обычных клавиш.
Tab открывает список мест, затем раздел маршрута и показанной свечи;
после последнего раздела возвращает обычное управление игры. Стрелки выбирают
место, Home/End переходят к краям списка. Просмотр не двигает героя.
Space/F1 проверяет путь без замены текущего запроса Seeker героя.
Enter запускает оригинальный приказ движения, Escape останавливает обычный Move.
При поиске Escape сначала очищает поиск; печатный поиск host пока не подключён,
это прежняя граница общего управления, а не новая возможность M4.

Для раскрытого места используется Hero.AcceptTarget(TargetChange), как в
Targeting.RetargetSelected. Игра сама выбирает точку подхода, стоимость,
препятствия и событие при прибытии. Вблизи (<4 единиц) сохраняется исходный
путь немедленного взаимодействия. Частичный значок имеет общую подпись,
направление и расстояние; движение к нему проходит через штатный GoTo с A*,
без скрытого target и автоматического запуска неизвестного события.
После раскрытия событие выбирается отдельным Enter.

Направление относительно текущего горизонтального направления камеры:
впереди, справа, позади и промежуточные направления. Расстояние по прямой
отделено от длины пути; единицы карты не названы метрами без доказательства.
Неполный/пустой/некорректный путь не запускает подход. Запрос пути выполняется
только по явной команде, а не при построении списка каждый кадр.

Список читает раскрытые активные VLocation либо показанные значки миникарты.
Учитываются FullyVisible, VisibleToPlayer, ShouldBeVisible, загрузка спрайта,
границы биома и видимость Canvas. Частичные значки не раскрывают имя, состояние,
врагов, награды или диалог. При исчезновении цели останавливается только
собственный приказ; замещающий приказ обычного управления не отменяется.
Повторная генерация карты создаёт новые узлы; одинаковые названия различаются
идентичностью модели, направлением и расстоянием.

Продвижение сообщается при изменении расстояния на очередные десять единиц,
отсутствие продвижения восемь секунд — один раз до возобновления движения.
Игра сама может прервать приказ. Сообщение о прибытии требует фактической
близости к всё ещё показанной цели. Окно справки, игровые окна и Alt+Tab
перебазируют отсчёт ожидания; возврат после отсутствующих кадров тоже учтён.
Под диалогом и боем сохраняется положение обзора; их управление остаётся
исходным путём M2/M3. Панель места закрывается исходным ModalDismissed.

Свечи читаются из видимого счётчика, полоски и исходного tooltip HUD.
Автоматические сообщения сравнивают четверти полоски, количество и показанный
эффект Искажения; кадры анимации не озвучиваются подряд. Зажечь свечу можно
исходным ARButton. Вражеская группа объявляется лишь при реально показанных
иконках VLocationBrief; внутренние EnemyTemplates не читаются.
Будущие воздействия Искажения, колода, награды и скрытые события не сканируются.

## Выполненные проверки

- Implemented: все шесть частей M4 подключены для исследованной сборки.
- Portable-tested: scripts/test.ps1 — Graph 94, Runtime 91, Windows 18
  утверждений, Python 21; ошибок 0. Семь новых сценариев проверяют направления,
  обходной/неполный/пустой путь, запрет скрытого чтения, пассивный просмотр,
  исчезновение/замену/перестановку объектов, продвижение/застревание, окно,
  удержание Enter и возврат из события. Это проверка модели, не живой Unity UI.
- Compiled-with-game: scripts/build.ps1, netstandard2.0, ошибок и предупреждений 0.
  BindingChecks разрешил все новые типы/поля/методы и три getters VHeroKeys.
  Проверка метаданных не вызывает оригинальные действия.
- Installed: scripts/deploy.ps1 при закрытой игре; шесть файлов сверены с пакетом,
  предыдущая 0.3.4 сохранена в проверенной резервной копии. A* dependency
  дополнительно включена в сверку build/deploy и runtime SHA-256/MVID.
- In-game-tested: новые пути 0.4.0 пока не проверены.
- Blind-user-accepted: отсутствует; gate M4 остаётся открытым.

Четыре пути ввода: ранний poller; живые назначения GameUI/Rewired;
исходные UI/Unity Submit guards; собственная модальная справка.
Дополнительно найдены и защищены прямые getters Horizontal/Vertical/
CameraRotation у VHeroKeys. Подавляются только присвоенные источники текущего
кадра; другие физические клавиши и независимый контроллер остаются игре.
Engine-wide Input patches и прямые изменения позиции не используются.

## Сценарий проверки в игре с NVDA

1. Обычным путём выйти из боя/диалога. Tab открыть обзор; стрелками прочитать
   несколько мест и проверить, что герой стоит. Одинаковые названия различимы.
2. Space сравнить расстояние по прямой и путь; найти препятствие/границу.
   Недостижимая цель не должна начать движение или открыть событие.
3. Enter начать подход к раскрытому месту; удержать Enter и стрелку.
   Приказ один, просмотр списка не добавляет движение; другие игровые клавиши
   остаются доступными после выхода из обзора через Tab.
4. Escape остановить посреди маршрута, отпустить, Enter повторить подход.
   При блокировке получить сообщение о застревании без телепортации/продолжения.
5. Удерживать Enter при Alt+Tab и возврате. Приказ не повторяется;
   следующее нажатие после отпускания работает, ложной остановки нет.
6. Подойти к событию, прочитать диалог/войти в бой штатно, выйти.
   Возвращается прежнее место обзора; удерживаемая клавиша не действует в новом окне.
7. Проверить частичный значок: общая подпись, без скрытого имени/врагов;
   подход раскрывает его обычной игрой, событие требует следующего решения.
   Перейти границу биома и естественно сменить процедурную карту.
8. Прочитать свечи и tooltip; зажечь одну. Количество и полоска меняются по
   правилам игры, удержание не расходует ещё свечу. Сравнить видимый эффект
   Искажения и сообщения с фактическим UI.

Записать услышанное, фактическое действие, повторное нажатие и возврат отдельно.
Не изменять сохранение, туман, ресурсы или разблокировки ради проверки.
Все магазинные/деревенские услуги и полный цикл забега относятся к M5;
исторические неподтверждённые разновидности M3 этим этапом не принимаются.
