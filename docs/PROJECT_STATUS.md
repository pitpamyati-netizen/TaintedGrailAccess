# Текущее состояние проекта

## Текущая версия M4 — 0.4.3, 13 октября 2026

Реализованы обзор раскрытых мест/частичных маркеров, направления относительно
камеры, расстояние по прямой и отдельная длина A* пути, исходное движение,
отмена, продвижение/застревание, границы биомов, возврат из диалога/боя,
процедурная замена карты и только показанные сведения свечи/опасностей.
Прямой опрос движения VHeroKeys получает те же узкие правила владения,
что GameUI. Скрытые имена/враги/будущие события не читаются.

В живой проверке 0.4.0 пользователь сообщил, что путь заканчивается раньше
цели и подход не начинается. Журнал подтвердил ошибочный запрет со стороны
мода до исходного обработчика. В 0.4.1 Enter передаёт решение игре;
Space остаётся предварительной оценкой с раздельными отклонениями начала/конца.
В 0.4.1 журнал подтвердил два подхода с диалогом и возвратом. Пользователь
сообщил о пропущенных именах и непостоянном взаимодействии. В 0.4.2 читается
показанное имя/подсказка либо «Место без названия», когда игра даёт многоточие.
Обычная подсказка не блокирует Enter, окно выбора сохраняет приоритет.
Запрет игры на взаимодействие поясняется отдельно от возможности подхода.

В 0.4.2 пользователь сообщил о безымянных местах и ошибочном отказе одновременно
с разыгранной картой. Журнал подтвердил исходный вызов и применение карт.
В 0.4.3 безымянные места/частичные маркеры получают устойчивые номера;
временное отключение кнопки после ApplyClick читается как выполнение действия,
один раз. Пользователь выбрал сохранение быстрого розыгрыша по единственной цели.

Implemented: M4 для точной GOG 1.61. Portable-tested: Graph 94, Runtime 96,
Windows 18 утверждений, Python 21, ошибок 0. Compiled-with-game: успешная
сборка и BindingChecks. Installed: шесть файлов пакета проверены, предыдущая
0.4.2 сохранена в проверенной копии. In-game-tested: отказ 0.4.0, подходы
0.4.1 и применение карт 0.4.2 подтверждены журналом; 0.4.3 ещё не проверена. Blind-user-accepted:
имена/взаимодействие и полный M4 ещё не приняты.
Следующий шаг — прочитать несколько разных номеров мест и проверить карту
по одной/нескольким целям без ошибочного отказа; затем сценарий [M4_VERIFICATION.md](M4_VERIFICATION.md):
Tab → обзор без движения → Space → Enter → Escape → повторный подход → событие
→ возврат, затем удержание/Alt+Tab, частичный маркер, границы и свеча.
Требуется повторная проверка после исправления; отказ 0.4.0 не означает принятие.
Открытые проверки M3 сохранены ниже. Игровые данные и личные журналы не публикуются.

Предыдущий результат M3: была установлена версия 0.3.4, Conquest GOG 1.61, Unity 2020.3.23f1,
Mono x64, BepInEx 5.4.23.5. План — [ROADMAP.md](../ROADMAP.md), привязки —
[GAME_API.md](GAME_API.md), проверки — [TEST_RESULTS.md](TEST_RESULTS.md).

## Что реализовано

M0–M2 завершены в исходниках для исследованной установки. Доступны стартовая
подсказка, меню, настройки всех обнаруженных типов, подтверждения, выбор режима
и ячейки, имя/пол героя, загрузочное подтверждение, начальные диалоги, выбор
класса/начального умения/доступной сложности и вход в первый бой.
Обучение сохраняет ограничения классов и сложности самой игры.

Для M3 добавлены разделы боя, живые цены/стороны карт, просмотр без розыгрыша,
исходные розыгрыш/цель/отмена/конец хода, выбор N карт, общий ultimate,
классовая колода, показанные статусы/намерения, журнал и кнопки наград.
В 0.3.4 исправлено чтение описания при пустом tooltip и различение повторяющихся
кнопок награды; добавлены видимые пороги ultimate, состояние карт классовой
колоды, номер уровня прислужника и текст механики внутри классовой подсказки.
Сохранение карты имеет отдельные разделы выбора/подтверждения и живую отметку.
Общие пути девяти классов — [m3-class-coverage.md](research/m3-class-coverage.md).
Готовая реализация ещё не означает завершение M3: несколько разных боёв и
все классовые варианты с NVDA не приняты. Подробности — [M3_VERIFICATION.md](M3_VERIFICATION.md).

Ввод включается явным `Accessibility.EnableTitleInput=true`; default false.
Точные SHA-256/MVID TG.Main, Rewired, Unity UI и TMP проверяются до установки
hooks. При несовпадении остаётся обычное управление и диагностический режим.
Все действия вызывают оригинальные обработчики; мод не меняет состояние забега
напрямую. Настоящий текстовый редактор получает обычные клавиши игры, Ctrl+F1
читает текст/выделение, Ctrl+Enter завершает. Личный текст не пишется в журнал.
Отправка формы сообщения об ошибке не предоставляется.

World выбирается заново из загрузочной, основной или стартовой сцены. Между
кадрами нет сохранённых view/callbacks; постоянны только состояние экрана,
строки речевого сравнения, metadata и слабые ссылки контроллеров.
Покрытый экран сохраняет место, ввод подавляется только по присвоенным клавишам.

  очищается; значки сопоставляются с живой таблицей игры без выдуманных названий.
  M3: живые зоны/карты/цели/выбор/ultimate/эффекты/журнал/награды; полный

- Portable-tested: Graph 94, Runtime 84, Windows 18 утверждений, Python 21.
  Проверены редактирование/Unicode/защищённое поле, частная речь, сцена с
  удерживаемым Enter, приоритет загрузки и сохранение смысла оформления.
  Новые проверки: пассивный просмотр/свежесть карточного действия, одинаковые
  экземпляры/удаление, min/max выбора, 32 отрицательных/положительных сочетания
  условий цели, повтор/замена журнала и недействующий статус. В 0.3.4 также
  проверены пустое/скрытое описание, вложенный просмотр колоды/сторон и
  повторяющиеся кнопки награды без старого действия после их исчезновения.
  Возврат прежней политики чтения и ключей дал два ожидаемых сбоя; после
  восстановления исправления все проверки прошли. Это не игровой сценарий.
- Compiled-with-game: netstandard2.0, SDK 10.0.301, 0 ошибок/предупреждений.
  BindingChecks нашёл точные типы/поля/сигнатуры. Пакет — четыре собственные DLL,

  проверка on/off и повторного ввода этого уточнения остаётся открытой.
- In-game-tested: для новых путей 0.3.4 отсутствует; результаты ниже исторические.

## Исправленные остановки

После «Начать игру» ожидание находилось в отдельном World ScenePreloader,
поверх уже готовой BaseScene. Теперь живое загрузочное окно имеет приоритет,
а «Продолжить» появляется только после готовности и вызывает штатный handler.
Начальная история использует VBigPopupUI, а последняя реплика ожидает
KeyboardListenerForInput. Оба варианта подключены; продолжение выполняет сама
игра. Удерживаемый Enter сохраняет владение при смене сцены и не повторяется.

## Открытая проверка предыдущего M3

В установленной 0.3.4 при естественном появлении окна сохранения карты проверить
Enter → выбор карты, Tab → подтверждение, Enter → следующий раунд. Ответ
пользователя 13 октября: «Такое окно пока не появилось». Запись исходного
подтверждения добавлена в диагностику; остановка в игре не воспроизведена.
Не обходить ранний выход EndTurn прямой записью флага или повтором эффектов.
Завершить игровую проверку M3 по M3_VERIFICATION: несколько боёв без мыши,
многошаговый выбор, смерть цели, разные классы, победа/награды/поражение,
удержание и возврат окна. Первый бой 0.3.0 пользователь прошёл с NVDA.
Сводки и возврат в руку 0.3.1 подтверждены. В установленной 0.3.2 пользователь
проверил меню Escape с NVDA: открытие, удержание, чтение пунктов стрелками,
закрытие отдельным нажатием и повторное открытие работают.
Проверка выбора цели тоже принята: удержание Escape отменяет выбор без меню,
фокус остаётся в руке, последующий розыгрыш Enter → выбор цели → Enter работает.
В 0.3.3 после сообщения о значках B/CS/JP/RD/Ta/GT исправлены названия
ресурсов; пользователь с NVDA подтвердил чтение и получение доступной награды.
Окно выбора нескольких карт либо сохранения карты на следующий ход пока
не встретилось пользователю; проверка этих окон остаётся открытой.
Удержание Enter при подтверждении цели проверено: карта разыгрывается один раз.
Удержание при Alt+Tab и возврате тоже принято: повторного розыгрыша нет,
следующее нажатие после отпускания работает. Дальше — выбор нескольких карт
и сохранение карты при естественном появлении окна, затем — остальные
боевые варианты. Пользователь сообщил: «Пока доступен только Егерь».
Остальные классы проверяются после обычной разблокировки в прохождении;
их механики ещё не приняты с NVDA. Сохранения и условия разблокировки
не изменялись. Очистка поиска при удержании Escape ещё не принята.
В штатном HeroFighter.EndTurn найден статически
подтверждённый ранний выход после появления CardToStaySelector; возможное
зависание сохранения карты требует живого воспроизведения. Прямым изменением
игрового флага оно не обходится.
Исследование, весь забег, другие сборки и JAWS/Tolk/SAPI не приняты.
Игровые DLL, декомпиляция, сохранения, журналы и личные конфиги не публикуются.
Исторические результаты сохранены в TEST_RESULTS и GAME_API.
