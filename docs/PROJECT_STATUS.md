Python 21 — без ошибок. Host 0.1.2 собран build.ps1 с настоящими игровыми ссылками,

## Первый игровой результат, 12 октября 2026

Русская GOG-установка Conquest: build `59087960036481007`, Application.version
`1.61`, Unity `2020.3.23f1`, Mono, Windows x64. В исходной установке загрузчика
не было; добавлен официальный BepInEx 5.4.23.5 с проверкой SHA-256. Файлы нового
загрузчика перечислены с hash в локальном loader-install.json. Другой loader не заменялся.
Игровые DLL и сохранения установщиком не менялись. NVDA Controller Client
2026.2 x64 подключён отдельно, запасной SAPI выключен.

Плагин собран и установлен через build/deploy. Обновление создало проверенную
резервную копию 0.1.0. На двух запусках журнал подтвердил загрузку и принятую речь
NVDA. Пользователь подтвердил слышимость стартовой фразы, затем названия
«Стартовый экран» и игрового текста `Press any button`. На этом запуске игра
показала английскую подсказку; мод передал её без самостоятельного перевода.
Журнал зафиксировал видимость, одно чтение и исчезновение подсказки.

Пассивный адаптер допускает только точный SHA-256/MVID TG.Main и версии выше.
Он наблюдает TitleScreen.LateUpdate; живой владелец освобождается в конце кадра.
Неизвестная сборка оставляет диагностический режим. Полный профиль хранится
локально; разрешения игровых действий и владения вводом остаются false.

Проверки: Graph 94, Runtime 34, Windows 15 утверждений, Python 21 — без ошибок.
Сборка .NET SDK 10.0.301 / netstandard2.0 с игровыми DLL — без предупреждений.
Исправлены запрет нового SDK и зависевший от ОС тест WSL-путей.
Приёмка слепым пользователем подтверждена только для первого текста, не всего UI.

## Принятые решения

Graph остаётся BCL-only. Используется параллельное дерево с живыми данными,
GraphState на экран, одним источником фокусной речи и original action handlers.
Непроверенный fingerprint сохраняет диагностический режим и обычное управление.
Tolk необязателен; русский язык мода и текущая локализация игры различаются.
Пути к игре и личные профили не публикуются. Git не выполняется автоматически.

## Следующий игровой шаг

Испытать собранную диагностику 0.1.2 на обратимом параметре, включая удержание,
отпускание, Alt+Tab, подтверждение и назначение клавиши. Подтвердить ранний
опрос относительно всех путей, живые карты Rewired, точечное подавление и
ownership guard без дубля Submit. Затем подключить главное меню, согласие/условия,
настройки и возврат. Первое активное действие проверять на обратимом параметре,
включая повтор, удержание и Alt+Tab. Пока управление меню не предоставлено игроку.

При продолжении обновлять эту запись только подтверждённым результатом,
текущим ограничением и следующим необходимым действием. Игровые тесты ещё
не передавались пользователю как работающая функция.
