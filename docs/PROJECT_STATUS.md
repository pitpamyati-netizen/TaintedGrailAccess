## Что пока не подтверждено

- Установка пользователя, fingerprint игры, runtime и совместимость host.
- Реальные UI handlers, клавиши, видимость, модальность и hooks ввода.
- Первый законченный путь в игре и слышимый вывод NVDA на этой сборке.
- Самостоятельное прохождение и принятие слепым пользователем.

M0 реализован в переносимой части; игровые проверки M0 и этапы M1–M6 остаются
незавершёнными. Отдельные уровни доказательства не объединяются в «мод готов».

## Принятые решения

Graph остаётся BCL-only. Используется параллельное дерево с живыми данными,
GraphState на экран, одним источником фокусной речи и original action handlers.
Непроверенный fingerprint сохраняет диагностический режим и обычное управление.
Tolk необязателен; русский язык мода и текущая локализация игры различаются.
Пути к игре и личные профили не публикуются. Git не выполняется автоматически.

## Следующий игровой шаг

Получить настоящий путь Conquest и read-only inventory, затем журнал загрузки.
Записать факты в [GAME_API.md](GAME_API.md). Найти и проверить ввод/handlers
для пути «старт → меню → настройки → изменение одного параметра → назад».
Для подключения этого пути нужна настоящая игровая сборка и проверка NVDA.
Это ограничение интеграции; оно не блокирует независимую документацию.

При продолжении обновлять эту запись только подтверждённым результатом,
текущим ограничением и следующим необходимым действием. Игровые тесты ещё
не передавались пользователю как работающая функция.
