Обновлено 13 октября 2026. План — [ROADMAP.md](../ROADMAP.md), доказательства —
[GAME_API.md](GAME_API.md), проверки — [TEST_RESULTS.md](TEST_RESULTS.md).
Происхождение формы записи — [template-import.md](research/template-import.md).

## Что реализовано

M0 завершён. В 0.1.3 реализован M1 на исследованной GOG 1.61:
ранний опрос клавиатуры перед всеми обнаруженными путями ввода, живые карты
Rewired, точечное подавление собственных сочетаний, защита от повторного Submit,
удержание/отпускание, Alt+Tab, raw capture, текстовое поле и модальная справка.
Включается явным `Accessibility.EnableTitleInput=true`; default false.
Несовпадение SHA-256/MVID закрывает активные привязки и оставляет игру управляемой.

Для проверки подключён стартовый путь: меню, вкладки, переключатели, назначение
клавиш, кнопки настроек/подтверждения, согласие и форма сообщения об ошибке.
Все действия используют исходные обработчики. Форма не предоставляет отправку;
введённые слова не читаются в диагностику. Живые view и delegates между кадрами
не сохраняются, ссылка World освобождается после каждого опроса.

## Проверки и границы

Implemented: физический ввод M1 и ограниченные адаптеры стартовой сцены.
Portable-tested: Graph 94, Runtime 53, Windows 15 утверждений, Python 21.
Compiled-with-game: netstandard2.0, SDK 10.0.301, 0 ошибок/предупреждений;
пакет — четыре собственные DLL и две таблицы локализации.
In-game-tested: настоящий запуск, меню/настройки, original-handler вызовы,
переключение параметра один раз, Rewired/Submit, справка, rebind/cancel, popup.
Blind-user-accepted: пользователь подтвердил меню, удержание/повтор, Alt+Tab,
справку, отмену назначения и возврат из подтверждения. После исправления входа
в текстовое поле проверены native selection, набор/удаление и закрытие Escape.
Пользователь подтвердил отсутствие чтения пунктов во время редактирования.
Озвучивание букв и речевой просмотр текста пока отсутствуют; это ограничение M2.

Отключение EnableTitleInput проверено отдельным запуском: input hooks отсутствуют,
обычная клавиша закрывает PressStart. Пользователь слышит только стартовую
подсказку. После закрытия флаг возвращён в true, доступное меню снова включено.
Обновления установлены через build/deploy с проверенными резервными копиями.

## Исправленные проблемы

Главное меню находится в Model.Views, а не MainView; добавлена регрессия выбора
видимого view. Вложенный original-handler больше не очищает World внешнего
опроса, поэтому место после действия сохраняется. Native text editor получает
собственную selection только для ввода; открывающий Enter не завершает поле
повторно. Его состояние проверяется без записи содержимого.

## Что дальше

M1 завершён для исследованной стартовой сцены; исходники подготовлены для
commit/push по текущему поручению. Следующий этап M2: полный стартовый путь,
все типы настроек, речевое редактирование текста, условия, обучение,
выбор класса и первый бой.
M3–M6 не реализованы. Полное прохождение и JAWS не проверены.

Graph остаётся BCL-only, интерфейс строится параллельным деревом с живыми данными.
Профиль unbound.example намеренно неподключён. Игровые DLL, дампы, сохранения,
личные пути и конфигурация не публикуются. Git выполняется только по поручению.
Исторические результаты 0.1.1/0.1.2 сохранены в TEST_RESULTS и GAME_API.
