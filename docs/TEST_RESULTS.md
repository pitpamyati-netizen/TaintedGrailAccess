# Фактические проверки проекта

## M1, 0.1.3, 13 октября 2026

Implemented: ранний физический input host и ограниченный стартовый путь.
Portable-tested: `scripts/test.ps1` — Graph 94, Runtime 53, Windows 15 утверждений,
Python inventory 21, 0 ошибок. Восемь новых сценариев покрывают ownership между
повторами/на отпускании, scope, raw opener, независимые contributors, blur/disable,
modal/text/unfocused, exception после действия и non-main живой view меню.
Compiled-with-game: `scripts/build.ps1 -Target Diagnostics -NonSteam`, SDK 10.0.301,
netstandard2.0; 0 ошибок/предупреждений. Пакет: только четыре собственные DLL и
две локализации, точные игровые ссылки проверяет build/deploy.

In-game-tested: GOG build 59087960036481007, version 1.61, Unity 2020.3.23f1,
Mono x64, BepInEx 5.4.23.5, NVDA. Реальный журнал показывает ранний poll и
suppression GameUI/Rewired, original-handler вызовы и два обратных изменения
переключателя, работу справки, rebind/cancel и popup. Полный журнал не публикуется.
Blind-user-accepted: пользователь подтвердил меню и сценарий 2–6, затем отдельно
назначение с отменой и возврат «Выйти → Нет». При уточняющей проверке выявлена
проблема входа в текстовый редактор; после исправления native selection пользователь
подтвердил прекращение чтения пунктов и закрытие Escape. Журнал подтвердил
focused/selected/readOnly=False и набор/удаление по длине 0→4 и 4→3 без записи
символов. Озвучивание букв и просмотр текста пока не реализованы и остаются M2.
Ответ «всё работает» не заменяет последующий уточнённый результат.

Отключение проверено отдельным запуском: PASSIVE_DIAGNOSTICS, title-input patches
не устанавливаются, PressStart исчезает после обычного ввода; пользователь
слышит только стартовую подсказку. После закрытия вернули EnableTitleInput=true.
Обновления через deploy с резервной копией и сверкой SHA-256. Согласие/TOS найдены
статически; их полное живое чтение и весь путь M2 не принимаются как завершённые.
Подробнее — [M1_VERIFICATION.md](M1_VERIFICATION.md).

M1 принят в объёме владения клавиатурой исследованной стартовой сцены.
Весь путь M2, геймпад, иные версии игры и другие речевые backends не принимаются.

## Метод проверки

Среда: Linux, официальный .NET SDK 8.0.425, тестовый runtime .NET 8.0.31,
Python 3.12.14. В этой среде обычный CLI SDK не запускался из-за недоступной
системной информации о времени старта процесса. Был применён включённый в архив
[verify_core.py](../scripts/verify_core.py): прямой вызов Roslyn из SDK,
отдельная компиляция трёх библиотек и трёх тестовых executable, затем их запуск.
Для библиотек использованы reference assemblies официального пакета
NETStandard.Library 2.0.3. Тестовые executable выполнялись на .NET 8.

Команда принимает собственные пути установленного SDK и reference package:

```text
python3 scripts/verify_core.py --sdk-root <SDK_ROOT> --netstandard-ref <NETSTANDARD_2_0_REF>
```

SDK, NuGet-пакет, reference DLL, тестовые бинарные файлы и промежуточные журналы
не входят в исходный архив. Подставные типы Unity/BepInEx для объявления host
«скомпилированным» не использовались. Компиляция C# не заменяет проверку MSBuild,
которую ещё нужно выполнить на пользовательской Windows-установке.

## Существенные регрессии, покрытые тестами

- Дубликаты одинаковых карт различаются по идентичности экземпляра; исчезновение
  текущего элемента восстанавливает ближайшего предыдущего выжившего.
- Перестройка графа и смена модальности не используют устаревшие действия узлов.
- Присвоенный Enter остаётся заблокированным в игровом и toolkit-пути до конца
  кадра, даже если действие сразу закрыло модаль или открыло raw capture.
- Исключение после действия не возвращает клавишу игре и не вызывает повторный
  Submit; optional sound/live callbacks не повторяют уже объявленный фокус.
- Реальное текстовое поле и raw capture отключают навигацию/поиск; фокус экрана
  сохраняется для возврата. Space читает tooltip и не превращается в поиск.
- Объявление собственного изменения состояния перебазирует Live-watch;
  SpeaksOwnExpansion с live part не теряет новую реплику.
- Выбранный игровой элемент определяет начальный фокус независимо от того,
  отключена ли речевая часть `selected`. Допустимый suggested move имеет приоритет
  над InitialFocusStop; недопустимый не усаживает StartUnfocused курсор.

Подробная связь требований с кодом и проверками, включая неоднозначности Draft 1,
описана в [SPEC_CONFORMANCE.md](SPEC_CONFORMANCE.md).

## Что не было проверено при подготовке архива

- Обычная MSBuild-сборка `.csproj` в Windows и выполнение PowerShell-скриптов.
  Скрипты сборки/установки прочитаны и проверены статически; это не испытание
  реальной установки, резервного копирования или отката.
- Компиляция `TaintedGrailAccess.BepInEx` против настоящих BepInEx/Unity DLL.
- Загрузка диагностического host в Conquest и подтверждение точной версии игры.
- Реальная речь NVDA, JAWS/Tolk или SAPI, её слышимость, темп и очередь.
- Реальные screen bindings, Rewired/EventSystem/Unity hooks и порядок кадров.
- Карточный бой, выбор целей, исследование, передвижение и полный забег без зрения.
- Производительность на большой сцене, длительная сессия и восстановление
  после игровых исключений, обновления игры или загрузчика.

Для этих пунктов есть 26 сценариев в [ACCEPTANCE_TESTS.md](ACCEPTANCE_TESTS.md)
и этапы в [ROADMAP.md](../ROADMAP.md). Они остаются незавершёнными до фактического
прогона с фиксацией версий, ожидаемого результата и результата пользователя.

## Происхождение тестов и границы вывода

Это новый набор, написанный для этого проекта по предоставленной спецификации.
Он не является полученным оригинальным набором примерно из ста тестов,
упомянутым во вложении, и не доказывает полную совместимость с неизвестной
upstream-реализацией. Число 15 у Windows — число утверждений, а не отдельных
пользовательских сценариев. Складывать все числа в единый показатель готовности
мода не следует.

При изменении исходников этот отчёт становится историческим. Повторите нужные
проверки и обновите JSON/дату; не отмечайте игровые шаги выполненными только
потому, что portable-тесты остались зелёными.
