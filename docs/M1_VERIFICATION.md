# Проверка M1 с NVDA

Сборка 0.1.3 предназначена для проверки ввода в стартовой сцене GOG 1.61.
Это не готовое прохождение. Ползунки, списки настроек, обучение, бой и движение
относятся к следующим этапам. `Accessibility.EnableTitleInput=true` включает
проверочный путь; `false` после перезапуска возвращает пассивное чтение.

## Короткий сценарий

1. Запустить игру с NVDA. Отпустить клавиши, затем нажать Enter на стартовой
   подсказке. Стрелками найти «Настройки», нажать Enter и отпустить.
2. Tab перейти из вкладок к параметрам. На «Показывать вступительный ролик»
   удержать Enter около секунды. Состояние меняется один раз; место сохраняется.
   Отпустить Enter и нажать ещё раз: состояние возвращается, новое значение
   читается один раз. Не применять изменения, если исходное значение не вернулось.
3. Удерживая стрелку, проверить последовательное чтение без скачков. Затем
   удерживая Enter перейти Alt+Tab в другое окно и обратно, отпустить Enter.
   Сам возврат окна не должен снова менять параметр. Следующее отдельное
   нажатие должно работать. Escape открывает штатное подтверждение, если
   параметры отличаются; выбрать отмену/возврат без сохранения изменения.
4. В меню нажать Ctrl+F1. Открывается справка мода. Нажать букву и Space:
   игровое действие под справкой не выполняется. Escape закрывает справку,
   прежний пункт меню снова читается. Обычный Alt+Tab остаётся доступен.
5. Открыть настройки, выбрать вкладку «Клавиатура» стрелками и Enter, затем
   Tab перейти к назначениям. На любой строке нажать Enter и отпустить:
   окно просит новую клавишу, открывающий Enter не назначается сам.
   Escape отменяет. Повторить открытие и отмену; прежнее назначение сохраняется.
6. Для проверки настоящего текстового поля выбрать вкладку «Игра», Tab к
   параметрам, кнопку сообщения об ошибке. Открывается штатная форма.
   Enter на заголовке включает ввод; набрать короткий тестовый текст,
   использовать стрелки и Backspace. Мод не запускает поиск и не произносит
   пункты меню поверх редактирования. Escape завершает ввод/закрывает форму
   штатным путём. Ничего не отправлять; кнопка отправки в проверочном дереве
   не предоставлена. Содержимое полей не входит в журнал мода.
7. В меню выбрать «Выйти», в подтверждении выбрать «Нет». Должен восстановиться
   прежний пункт. Затем закрыть игру штатно. Отключить EnableTitleInput и
   проверить, что обычные игровые клавиши снова проходят без подавления.

Результат нужен отдельно для каждого пункта: выполнен/не выполнен, услышанное
и наблюдаемая ошибка. Журнал проверяет вызовы исходных обработчиков и их
изменение состояния; принятую просьбу речи нельзя приравнивать к слышимости.

## Что проверяется автоматически

Снимки клавиш, удержание между повторами, отпускание, повтор действия,
переход в raw/text capture, независимые назначения одного действия,
модальное владение, отсутствие фокуса, исключение после действия и выключение.
Отдельная регрессия защищает меню, которое не является Model.MainView.
Сборка использует настоящие игровые ссылки, которые не копируются в пакет.

## Выполненный результат, 13 октября 2026

Implemented: ранний ввод, original-handler scope, per-chord подавление и
ограниченные стартовые адаптеры. Portable-tested: Graph 94, Runtime 53,
Windows 15 утверждений, Python 21. Compiled-with-game: 0 ошибок/предупреждений.
Отдельная BindingChecks разрешила точные поля с настоящими DLL без UI действий.

In-game-tested: пункт 1 и меню/настройки, два обратных изменения переключателя
по одному original-handler вызову, ранний опрос/подавление GameUI/Rewired,
справка, rebind/cancel и popup. Blind-user-accepted: пользователь подтвердил
слышимость меню, весь сценарий 2–6 первым ответом «всё работает», затем отдельно
rebind/cancel и «Выйти → Нет». Уточняющая проверка выявила проблему входа в
настоящий редактор. После исправления native selection повторный журнал
подтвердил focused=True, selected=True, readOnly=False и изменение длины 0→4
и 4→3. Введённые слова и символы в журнал не попали.

Пользователь подтвердил отсутствие чтения пунктов во время ввода и закрытие
через Escape. Это принятие передачи клавиатуры настоящему полю. Введённые
буквы не озвучиваются: речевой просмотр/редактирование текста остаются M2.
Полная доступность формы и её отправка этим сценарием не подтверждаются.

Пункт 7: возврат после «Нет» подтверждён пользователем. Отдельный запуск с
EnableTitleInput=false показал PASSIVE_DIAGNOSTICS без input patches;
обычный ввод закрыл PressStart. Пользователь слышал только стартовую подсказку.
После закрытия флаг возвращён в true; окончательная сборка испытана в игре.

M1 завершён в проверенном объёме владения клавиатурой стартовой сцены GOG 1.61.
Весь путь M2, другие сборки, геймпад и прочие речевые backends не приняты.
