# Клавиатура и речевой интерфейс

## Статус раскладки

В 0.2.0 базовые именованные клавиши подключены в исследованных сценах GOG 1.61
при `Accessibility.EnableTitleInput=true`. Меню, вкладки/переключатели,
назначение клавиши, подтверждения и Ctrl+F1 проверены с NVDA; подробности —
[M1_VERIFICATION.md](M1_VERIFICATION.md). Остальная таблица описывает контракт
навигатора и будущие экраны. Печатные символы host не использует для поиска:
они проходят игре, кроме собственной модальной справки. В настоящем текстовом
поле и rebind опрос навигации останавливается до выхода/отпускания клавиш.
В текстовом поле Ctrl+F1 читает выделение либо весь текст, Ctrl+Enter завершает
редактирование; остальные команды выполняет настоящий редактор игры.
Набор, удаление и выделение читаются NVDA без записи слов в диагностику.
В диалоге Tab переводит между текстом и действиями. «Продолжить» появляется
только при действующем ожидании нажатия самой игры. Подробные результаты —
[M2_VERIFICATION.md](M2_VERIFICATION.md).

## Базовое управление

| Клавиша | Действие |
| --- | --- |
| Стрелки | Перемещение по текущему разделу |
| Влево/вправо на ползунке | Изменение значения; Shift — крупный шаг |
| Вправо/влево на краю дерева | Раскрыть/войти; свернуть/вернуться к родителю |
| Tab / Shift+Tab | Следующий/предыдущий раздел; положение внутри раздела запоминается |
| Home / End | Первый/последний доступный элемент текущей линии или уровня дерева |
| Ctrl+стрелки | Переход между явно заданными подрегионами; без region сочетание остаётся игре |
| Enter | Основное действие текущего элемента |
| Shift+Enter / Ctrl+Enter | Только объявленное модифицированное действие |
| Backspace | Дополнительное действие; во время поиска удаляет последний символ запроса |
| Space / F1 | Подробное описание/tooltip; отсутствие описания озвучивается |
| Escape | Сначала сброс поиска, иначе штатный Back/Cancel текущего экрана |
| Печатный текст | Поиск в текущем разделе, если настоящего текстового поля нет |

Host повторяет навигацию после 0.4 секунды с шагом 0.08 секунды; очередь речи не задаёт частоту.
Ползунок использует исходный обработчик игры: обычный шаг — десятая часть
диапазона, Shift — пять таких шагов одним вызовом; пределы и округление сохраняет игра.
Удержание Enter не повторяет покупки, розыгрыш или другое расходное действие.
Реальная частота повторов задаётся физическим input adapter, не таймером речи.

При исследовании экран может начинать без accessibility focus: игровые
команды остаются игре. Tab устанавливает cursor, а Tab за последним разделом
возвращает обычное управление. Без cursor Enter, tooltip и secondary не
перехватываются. Native text field и keybinding capture отключают поиск.

Insert и CapsLock не используются: это клавиши NVDA. Не назначать глобальные
комбинации Windows, скринридера и раскладки. Alt-комбинации базовый навигатор
не переинтерпретирует как обычные стрелки. Итоговые дополнительные bindings
нужно выбрать и проверить вместе с установленной игрой.

## Дополнительные команды, которые ещё нужно подключить

Назначения следующие по смыслу, без неподтверждённых занятых клавиш:

- повтор текущего элемента и остановка речи;
- краткий статус героя/боя без ухода с выбранной карты;
- последние пять событий и полный журнал;
- обзор выбранной цели и её видимых состояний;
- список известных объектов, движение к выбранному, отмена движения;
- помощь по текущему экрану, настройки речи и клавиш;
- аварийное отключение accessibility focus с возвратом обычного ввода.

Номер карты не должен одновременно означать её просмотр и немедленный розыгрыш.
Быстрые действия вводятся только с понятным объявлением режима и возможности
отмены, после штатного targeting flow.

## Что и когда произносить

Короткий focus readout: имя элемента, существенное состояние/значение,
доступность, позиция. Для карты — то, что видно на самой карте; полный эффект,
расшифровки keywords и tooltip details вызываются отдельно. Пример формы
«название, стоимость, выбранная, 2 из 5» — шаблон, не текст реальной карты Conquest.

При переходе в новый раздел сначала произносится его название. При соседнем
переходе название раздела не повторяется. Возврат из modal восстанавливает
предыдущий элемент, если он существует, и объявляет понятный контекст.

Пользовательский запрос прерывает предыдущее сообщение. Автоматические события
и frame differ ждут в очереди. При синхронном изменении ползунка произносится
новое значение сразу; Live-watch не повторяет его. При фоновом изменении
читается только изменившаяся часть.

Навигация и речь должны работать быстро без искусственных задержек для
«антидубля». Дедупликация опирается на identity и источник изменения.

## Русский язык

Собственные строки мода — `locales/ru.properties`; английские — `en.properties`.
Startup и справка используют те же таблицы локализации.
Имена карт, NPC, эффекты и диалоги берутся из действующей игровой локализации.
Название класса не переводится вторично и не заменяется придуманным синонимом.

Сверять отображённый tooltip и речь на динамической стоимости/уроне, включая
ссылки и значимые иконки. Пустую локализацию не заменять скрытыми внутренними
значениями, раскрывающими недоступные игроку данные.

## Речевые backends

`auto` сначала пробует настроенный NVDA client, затем настроенный Tolk, затем
разрешённый SAPI fallback. Используется один backend. Native DLL не скачиваются
и должны соответствовать архитектуре Windows x64. Все вызовы выполняются в
потоке создания bridge.

Для NVDA `Speak(..., true)` отменяет предыдущую речь и отправляет новый текст;
`false` отправляет без явной отмены. Tolk получает свой interrupt flag.
SAPI использует асинхронный обычный текст и очистку очереди при interrupt.
Практический порядок и поведение при длинной очереди проверяются живым тестом.

`transcript` сохраняет запросы в журнал, но **не является речевым выводом**.
Лог различает speech.request и speech.accepted. Даже accepted означает успешный
ответ API, а не подтверждение, что пользователь услышал звук.
JAWS через Tolk — предусмотренный маршрут, а не уже протестированная поддержка.

## Подсказки и обзор журналов

Планируемый onboarding показывается при первом знакомстве и вызывается вручную
позже. В каждое нажатие не добавляются инструкции по Enter/Tab. По умолчанию
история читается короткими фрагментами примерно по пять строк; полный текст
доступен отдельно. Открытие обзора не сбрасывает выбранную карту/цель.
