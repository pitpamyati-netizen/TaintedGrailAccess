# Изменения

## 2026-10-13 — 0.2.0, работа над первым игровым путём M2

- Ползунки, списки, зависимые настройки и исходные tooltip; актуальные значения
  и большой шаг Shift через оригинальный обработчик ползунка.
- Речевой просмотр и редактирование настоящих полей: символы, удаление,
  выделение, Ctrl+F1 и Ctrl+Enter. Личный текст исключён из журналов.
- Выбор режима/ячейки, имя героя, класс/умение/сложность, видимые диалоги,
  текст и ссылки согласия; исходные UI handlers и ограничения игры.
- Контроллер игровой сцены и сохранение владения удерживаемым Enter при переходе;
  живые подсказки/субтитры и отдельное определение входа в бой.
- Исправлены две остановки: отдельное загрузочное окно промежуточной сцены
  и ожидание нажатия после диалога. Оба продолжаются исходными handlers игры.
- Игровое оформление очищается для речи; имена input icons берутся из живой
  таблицы игры, неизвестный значок обозначается явно. Личный текст не изменяется.
- Graph 94, Runtime 67, Windows 18 утверждений, Python 21; сборка и BindingChecks
  с игровыми DLL. Пользователь с NVDA принял ползунок, речевой редактор и
  самостоятельный путь создания героя/обучения до первого боя. Условия повторно
  не появлялись. Карточный бой — M3. См. docs/M2_VERIFICATION.md.

## 2026-10-13 — 0.1.3, M1: владение клавиатурой

- Ранний опрос перед GameUI/Rewired/EventSystem и точечное подавление сочетаний.
  Удержание Enter не повторяет действие; навигация повторяется; Alt+Tab ждёт отпускания.
- Исходные UI handlers проходят собственную область владения; физический Submit
  не вызывает действие повторно. KeyUp очищает штатное состояние игры.
- Подключён ограниченный стартовый путь: меню, вкладки/переключатели, кнопки,
  подтверждения, rebind/cancel и настоящий редактор текста. Ctrl+F1 — модальная справка.
- Живые views берутся из Model.Views, место после вложенного действия сохраняется.
  Неизвестная сборка/окно, native text и назначение клавиши возвращают управление игре.
- Добавлены 8 регрессионных тестов, проверены тесты, сборка с игровыми ссылками,
  обратимая установка и сценарии с NVDA. Полная матрица — docs/M1_VERIFICATION.md.
  Весь стартовый путь M2 и прохождение остаются будущей работой.

## 2026-10-12 — 0.1.2, исследование ввода стартового меню

- Найдены исходные пути меню, согласия, настроек, подтверждения и назначения клавиш.
  Уточнены сигнатуры и ограничения в GAME_API и отдельной записи исследования.
- Добавлена обработка снимков клавиатуры: удержание, отпускание, разные Enter,
  смена модификатора, возврат окна, raw/text capture и повтор навигации.
  Добавлены 11 тестов, включая одно действие через общий Runtime.
- Добавлена отключённая по умолчанию одноразовая диагностика порядка обработки
  ввода. Она не блокирует клавиши, не вызывает игровые действия и не пишет введённый текст.
- Проверены тесты и сборка с игровыми DLL; установка и игровая/NVDA-проверка 0.1.2
  ещё не выполнялись. Управление меню остаётся неподключённым.

## 2026-10-12 — 0.1.1, первый видимый текст

- Добавлено живое пассивное чтение стартовой подсказки через общий Graph/Navigator,
  ограниченное точным отпечатком GOG 1.61 и настоящей видимостью текста.
- Подтверждены запуск плагина, чтение и исчезновение подсказки; пользователь
  подтвердил слышимость через NVDA. Это не проверка управления меню.
- Исправлены совместимость скриптов с SDK 10 и переносимость проверки путей.

## 2026-10-12 — инструкции и исходники на GitHub

- Добавлены адаптированные правила разработки, проверки меню, локализации,
  диагностики, подготовки выпуска и работы с GitHub.
- Добавлены журнал подтверждённых игровых привязок и краткая запись состояния;
  неизвестные игровые сведения остались незаполненными.
- Записаны происхождение, лицензия, состав полезного переноса и исключённые советы.
- Уточнены правила хранения местных файлов, исправлены ссылки на отсутствовавший
  стартовый документ. Подготовлена первоначальная публикация исходников.

Игровые функции не изменены; готовый пользовательский выпуск не объявляется.
